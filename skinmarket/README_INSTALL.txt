SKINMARKET — готовый комплект Steam-only регистрации
======================================================

ВАЖНО: архив собран по присланному вами server.py и структуре проекта,
где server.py, db.py, steam_auth.py находятся в корне, а HTML — в templates/.

Установка:
1. Сделайте копию своей папки проекта и файла database.accdb.
2. Распакуйте содержимое архива в корень проекта с заменой файлов.
3. Убедитесь, что установлен requests:
   python -m pip install -r requirements.txt
4. Запустите приложение обычным способом:
   python server.py

Что изменено:
- server.py: маршрут /register перенаправляет на Steam, обычная регистрация отключена.
- steam_auth.py: Steam OpenID callback проверяет state, return_to, endpoint,
  SteamID и подпись ответа Steam; исправлена ошибка обработки state.
- templates/register.html: только регистрация через Steam.
- templates/login.html: вход через Steam и старый вход по логину/паролю.
- templates/profile.html: привязка/отвязка Steam в профиле.
- requirements.txt: requests.

Обычный вход по логину и паролю для уже существующих пользователей сохраняется.
Привязка Steam возможна только после входа в существующий аккаунт.
Если Steam ID уже связан с другим пользователем, повторная привязка запрещена.

База данных:
Таблица SteamAccounts создаётся автоматически при первом запросе.
Существующие таблицы и записи Пользователи не удаляются и не перестраиваются.

Ограничения перед реальным запуском:
- Steam OpenID не выдаёт email. Новым аккаунтам присваивается технический адрес
  steam_<SteamID>@steam.local. Для публичного сервиса добавьте сбор и подтверждение email.
- Нужен корректный публичный HTTPS URL в production. При reverse proxy настройте
  Flask ProxyFix/внешний host, чтобы callback Steam совпадал с фактическим адресом сайта.
- Проверьте интеграцию на копии database.accdb. Я проверил синтаксис Python-файлов,
  но не могу подтвердить успешный вход в Steam или совместимость с вашим локальным
  драйвером Access без запуска на вашем компьютере.

Архив не содержит database.accdb, secret.key, carts.json и других пользовательских данных.
