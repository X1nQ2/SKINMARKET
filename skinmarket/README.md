# SKINMARKET

Маркетплейс игровых скинов (в духе FunPay / GGSEL). Flask + Microsoft Access.
Оплата идёт на внутренний демо-баланс, реальные деньги не используются.

## Структура

    server.py        приложение Flask (маршруты и бизнес-логика)
    db.py            доступ к базе (pyodbc → Access)
    make_admin.py    создать администратора / назначить им пользователя
    fetch_game_images.py  скачивает картинки игр из Steam (нужен интернет)
    seed_demo.py     демо-данные: игры, скины, объявления, тестовые пользователи
    database.accdb   база данных (12 таблиц на русском)
    carts.json       корзины пользователей
    secret.key       ключ сессий (создаётся сам)
    templates/       HTML-шаблоны
    static/css/      стили
    static/js/       скрипты форм (фильтр категорий, предпросмотр картинки)
    static/game_images/  логотипы игр (cs2.png, dota2.png и загруженные game-<код>.*)
    static/skin_images/  картинки скинов, загруженные через сайт
    tests/           автотесты (pytest)

## Запуск

1. Установите Python 3.10+ и драйвер Access (**разрядность Python и Office/драйвера должна совпадать**:
   64-бит Python требует 64-бит Office или «Microsoft Access Database Engine 2016 Redistributable» x64).
2. Зависимости:

        pip install -r requirements.txt

3. (Необязательно) демо-данные:

        python seed_demo.py

4. Администратор:

        python make_admin.py ваш_логин

   Если пользователя нет, скрипт спросит email и пароль и создаст его.
5. Старт:

        python server.py

   Сайт: http://127.0.0.1:3000
   Из локальной сети: http://<IP-компьютера>:3000 (IP смотрите командой `ipconfig`).
   При первом запуске разрешите Python доступ в брандмауэре Windows (частная сеть).

Путь к базе можно поменять в файле `.env` (см. `.env.example`): `DB_PATH=C:\путь\database.accdb`.
Закройте `database.accdb` в Access перед запуском сайта.

## Роли

| Роль | Возможности |
|---|---|
| Покупатель | каталог, корзина, покупка, отмена оплаченного заказа, отзывы, баланс. Кнопка «Стать продавцом» в профиле |
| Продавец | всё выше + объявления, заказы покупателей («Товар передан») |
| Администратор | пользователи (блокировка, роли), снятие объявлений, справочники (игры, категории, редкости), статистика |

## Каталог и картинки

Админка → «Каталог»: добавление игр с логотипом, категорий, редкостей и скинов с картинкой, замена картинки у существующих скинов.
Картинку можно загрузить файлом (PNG, JPG, GIF, WEBP до 5 МБ; формат проверяется по содержимому) или указать ссылкой.
Продавец тоже может приложить файл в форме «Новое объявление». Один и тот же скин в одной игре — одна запись каталога, картинка общая.
При запуске `python server.py` в каталог автоматически добавляются игры CS2, Dota 2, Rust, Team Fortress 2, PUBG: Battlegrounds и Apex Legends с категориями (если их ещё нет).

Скин попадает на витрину только вместе с объявлением (цена + количество). В админке цену можно указать сразу при добавлении
скина или позже кнопкой «Выставить» в списке скинов. Цену и количество потом меняет раздел «Продажи».

Картинки игр: `python fetch_game_images.py` скачивает их из Steam для игр без логотипа (уже лежащие cs2.png и dota2.png
не перезаписываются). Картинки принадлежат правообладателям, используйте их только в учебном проекте.

## Как проходит сделка

1. Покупатель оплачивает заказ: деньги списываются с его баланса и удерживаются платформой. Статус «Оплачен».
2. Продавец передаёт товар и нажимает «Товар передан»: статус «Выполнен», деньги идут на баланс продавца.
3. До выполнения заказ можно отменить: деньги и количество возвращаются.
4. После выполнения покупатель может оставить отзыв (один на заказ).

## Тесты

    pytest

Тесты работают на временной базе SQLite с той же схемой (`tests/schema_sqlite.sql`), Access не нужен.

## Безопасность

По умолчанию пароли хранятся в базе открытым текстом (`PLAIN_PASSWORDS=1` в `.env`), чтобы их было видно в Access.
Это допустимо только для учебного стенда. Для реального сайта поставьте `PLAIN_PASSWORDS=0`: тогда хранится хеш.
Старые хеши продолжают работать при любом режиме. Формы защищены CSRF-токеном, SQL написан с параметрами,
баланс списывается атомарным `UPDATE ... WHERE Баланс >= сумма`.
